# DeskBoxToDo

> 选中一句话，直接变成待办。
> 仓库：https://github.com/Myles-jun/DeskBoxToDo

把「一句话」变成待办。选中文字按一下快捷键，确认窗里改两笔就完事。\r\n\r\n**两种用法**：自带待办（推荐，不依赖 DeskBox，加完立刻生效）或接入 [DeskBox](https://github.com/Tianyu199509/DeskBox) 的待办格子（和桌面小部件共享一份数据）。首次引导里选，之后随时可切换。

面向的场景很简单：群里发的作业通知、会议改期、截止提醒——不用先切窗口、打开待办、手打一遍。

![确认窗](docs/preview.png)

## 它做什么

- **选中 → 快捷键 → 确认**：三秒内把一段通知变一条待办
- **自动认时间**：`周五`、`明天下午三点`、`下周三 14:00`、`12月5日 上午9点` 都能算准
- **自动拆子项**：`第五章作业题：1（…），2（2）①②，2（3）` 会拆成四条子项
- **颜色标记**：红/橙/黄/绿/蓝/紫/青/粉，对应 DeskBox 自己的待办颜色
- **原文进备注**：整段消息原样保留，不会丢上下文
- **可选 AI**：默认关闭；打开后也是**手动**触发，只有你点「AI 重解析」才花 token
- **数据不出本机**：只有你主动使用 AI 时才联网

## 安装

1. 解压到任意目录（建议 `%LOCALAPPDATA%\Programs\DeskBoxToDo`）
2. 双击 `DeskBoxToDo.exe`
3. 跟着三步引导走：认识它 → 选快捷键 → 开机自启 / AI

**环境要求**：Windows 10 1809+ / Windows 11（自带 .NET Framework 4.8），无需安装运行时。
**关于 DeskBox**：默认「自带待办」模式不需要 DeskBox；想用桌面格子整理文件再装 [DeskBox](https://github.com/Tianyu199509/DeskBox)，然后在引导/设置里切到「接入 DeskBox」即可（数据格式一致，可随时切换）。

> 首次运行 Windows 可能提示"未知发布者"，因为安装包没有代码签名 —— 点「更多信息 → 仍要运行」即可。

## 使用

| 操作 | 说明 |
| --- | --- |
| 选中文字 → 快捷键 | 弹出确认窗（默认 Alt+Q） |
| 回车 / 点「加入 DeskBox」 | 写入并重启 DeskBox（约 2 秒） |
| Esc | 取消 |
| 「AI 重解析」 | 手动让模型重读这条消息（需先配置 Key） |
| 双击托盘图标 / 再次运行 exe | 打开待办窗口（单实例，第二次启动会把已有窗口调出来） |
| 提醒音乐 | 托盘右键 →「提醒音乐…」选一个 WAV；不选就用系统提示音；关掉「开机自启」不影响提醒 |\r\n| 日期 | 详情页「截止日期」打开「自定义日期」卡片：日期输入框 + 日历按钮、时间胶囊 + 时钟按钮（精确到 5 分钟），保存/取消 |\r\n| 窗口 | 拖动边缘/四角可缩放（最小 300×400，列表页与详情页都支持），尺寸会记住；顶部 48px 可拖动窗口 |\r\n| 待办窗口 | 每行是一块独立毛玻璃格子（悬停更亮）；仿 DeskBox：标题栏（＋ 新建 / ⋯ 更多）、带计数的页签（全部/今天/重要/已完成）、颜色筛选圆点、「添加待办」行、方形复选框行、底部「清除已完成」 |\r\n| 详情页 | 仿 DeskBox：← 返回 / ✓ 保存 / ☆ 重要 / 垃圾桶删除，大字标题，日期·提醒·重复·颜色 四宫格，步骤勾选、备注、添加文件、底部「创建于 …」 |\r\n| 新增待办 | 输入一句话回车 → 弹出**二级确认页**（标题/截止/重复/提醒/颜色/子项/备注/附件），确认后才写入 |\r\n| 右键待办 | 只有 6 项：完成 / 编辑详情 / 截止时间… / 重复… / 提醒… / 颜色… / 删除，选择多的会再开一层小面板 |\r\n| 右键托盘图标 | 打开待办 / 使用教程 / 设置 / 设置快捷键 / 开机自启 / 关于 / 退出 |\r\n| 托盘 →「打开待办」 | 打开自带待办列表：输入框回车新增、点圆圈完成、悬停右侧 ✕ 删除、右键改标题/清除时间 |

## 设置

托盘右键 →「设置…」：

- **启用 AI 解析**：总开关，关闭时一次 API 都不调
- **自动调用**：不勾 = 手动（默认），只有点「AI 重解析」时才调用；勾上 = 规则拿不准时自动调
- **API 地址 / 模型 / API Key**：默认 DeepSeek（`https://api.deepseek.com/v1` + `deepseek-chat`），任何 OpenAI 兼容接口都行
- **测试连接**：只发 `ping`（max_tokens=5），验证 Key 是否可用

省 token 的做法：固定短提示词、不带历史、只发当前这条（≤800 字）、`max_tokens=320`、同一条消息命中缓存不再计费；设置页显示上次用量。

## 桌面小组件

待办窗口支持三种摆放方式，点窗口右上角「桌面」按钮循环切换：**浮窗**（默认，随时可点可输入）→ **桌面 ✓**（固定在桌面层，像小组件）→ **置顶 ✓**（始终在最前）。托盘右键「固定在桌面（小组件）」可直接勾选。

- 常态在窗口层最下面（被其他窗口盖住，回到桌面才看见），不会浮在最上面挡事
- 拖动会记住位置（`config.json` 的 `todoWidgetBounds`），下次开机/启动回到原处
- 勾选「开机自动启动」后随 Windows 一起起来
- 再点一次「桌面 ✓」或托盘菜单即取消，变回普通浮窗（Esc/✕ 关闭）

## 待办功能是从 DeskBox 搬过来的

模型、重复规则、提醒、筛选排序都按 [DeskBox](https://github.com/Tianyu199509/DeskBox) 的实现移植，读写同一套 `todo.json` schema（version 3，字段名一致）：

| 能力 | 与 DeskBox 一致的行为 |
| --- | --- |
| 完成/取消完成 | 完成时若设了重复，立刻生成下一次（每周 +7 天、每月按锚点日子、工作日跳过周末），并把 `generatedNextItemId` 串起来 |
| 重复 | 不重复 / 每天 / 每周 / 每月 / 工作日；锚点是第一次设置的截止时间 |
| 提醒 | 每条可设「提前 0/5/10/15/30/60/1440 分钟」；默认 5 分钟；同一条到期日只提醒一次；可「稍后 10 分钟」 |
| 子项 | 子项逐条勾选，全部勾完自动把整条待办标记完成（和 DeskBox 一样） |
| 颜色/重要 | 8 种颜色标记 + 重要标记，颜色值与 DeskBox 完全对应 |
| 筛选 | 全部 / 未完成 / 今天 / 本周（周一起算）/ 本月 / 重要 / 已完成 |
| 排序 | 未完成在前、已完成在后，再按手动顺序、最后按更新时间 |
| 批量 | 清除已完成；每次改动进撤销栈（最多 30 步） |

（未搬的两块：附件与 Markdown 备注编辑器——自带模式只保存备注文本，附件仍需在 DeskBox 里管理。）

## 常见问题

**按了快捷键没反应？**
看日志 `%LOCALAPPDATA%\DeskBoxToDo\DeskBoxToDo.log`：没有 `hotkey pressed` 说明按键被别的软件（截图工具最爱抢 Alt+字母）用底层钩子吞了，换一个组合键即可。

**提示「没有取到选中的文字」？**
先用鼠标拖选文字，再按快捷键。微信/QQ 这类界面取词靠模拟 Ctrl+C，选中状态丢了就取不到。

**时间算错了？**
规则优先：明确写了 `14:00`、`下午三点` 时以规则为准；只说「周五」这种才允许 AI 补时间。

**会不会改坏我的待办？**
不会。写入前先让 DeskBox 退出，合并进 `todo.json`（保留原有条目），再把它启动回来；改动前会留 `.bak`。

## 卸载

托盘右键退出 → 删除安装目录 → 删除 `%LOCALAPPDATA%\DeskBoxToDo`（配置与日志）→ 删除注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\DeskBoxToDo`。
