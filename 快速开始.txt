DeskBoxToDo 快速开始
===================

1) 双击 DeskBoxToDo.exe
   首次启动会出现三步引导：认识它 / 选快捷键 / 两件小事。
   引导结束后程序常驻托盘（任务栏右下角，一个深色方块 + 白色对勾）。

2) 用一次
   在任意软件里用鼠标选中一段文字（比如群里的作业通知）
   按快捷键（引导里选的，默认 Alt+Q）
   确认窗弹出：标题、截止时间、子项、颜色都能改
   回车或点「加入 DeskBox」→ DeskBox 会重启约 2 秒 → 待办出现在格子里

3) 想改东西
   右键托盘图标：
   - 设置…          填 AI 的 API Key、切换自动/手动解析
   - 设置快捷键…    重新录制组合键
   - 使用教程        再看一遍引导
   - 开机自动启动    勾选状态就是当前状态
   - 关于           版本信息

4) 常见问题
   - 按了没反应：多半是组合键被别的软件（截图工具）抢了，换一个组合键。
   - 提示「没取到选中的文字」：先拖选文字再按，不要只把光标放上去。
   - 想让 AI 帮忙拆句子：设置里填 API Key（platform.deepseek.com），
     默认是手动模式，只在确认窗点「AI 重解析」时才调用。

5) 卸载
   托盘右键 → 退出
   删除安装目录（%LOCALAPPDATA%\Programs\DeskBoxToDo）
   删除配置（%LOCALAPPDATA%\DeskBoxToDo）
   如仍残留，删除注册表 HKCU\Software\Microsoft\Windows\CurrentVersion\Run 下的 DeskBoxToDo

数据都保存在本机，不会上传；只有你主动使用 AI 解析时才会联网。
